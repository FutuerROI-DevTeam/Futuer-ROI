### 分位点の境界（PR #86レビュー対応）

`P(G > t)`を`lgamma`の差のexpで浮動小数点計算すると、CDFが閾値にちょうど一致する境界で中央値・80%点が1日遅れる。α,β = 2〜20、q = 0.5 / 0.8の722件中15件で不一致（例：`(α,β) = (5,5)`で厳密には`P(G>1) = 0.5`なので中央値1日だが、浮動小数点では2日）。α・βは整数なので、本番は任意精度整数で比較する（[Architecture 手順4](../architecture.md#手順)）。境界例4件と、α = 2の閉形式`P(G>t) = β(β+1)/((β+t)(β+t+1))`との398件の照合はPASS（`bgq-boundary-check.mjs`、Node 24.21.0）。

## DPとMonte Carloの比較

- **恒等式**：a = 0.8、b = 0.3 で、SKIP開始の到達日分布と「DONE開始の分布 ⊕ Geometric(b)」の差は最大1.04e−17（0〜900日）。
- **期待値差**：4ユーザーとも、漸化式のΔと到達日分布DPの平均差が小数点以下6桁まで一致（例：B 4.444444）。
- **固定θでのMC（2,000試行）とDP**：P50・P80の差は最大1日。
- **CRNの効果（旧方式）**：P50差の標準偏差 1.09日 → 0.49日。DP方式ではCRN自体が不要。
- **実行時間**（Node 24.21.0、微小確率の打ち切りなし）：完了の目安（K=200、N=120）84ms、K=500で164ms。seedを変えた5回のP50は203〜212日（表示を週単位に丸める理由）。
- **最悪ケース（仕様どおりの乱数・サンプラー、微小確率の打ち切りなし、Node 24.21.0）**：配列を毎日作り直し刈り込みもしない素朴なDPでは`requiredFutureDone = 400`で約0.6秒、1095で約1.5〜1.7秒。配列の使い回しと「残り日数で届かない状態」の刈り込みを入れると、120・400・600・800・1000・1095の全条件で最大約260ms（need = 600）。分位点は両者で一致。Goalの上限は設けない。`bench.mjs` / `bench2.mjs`。
- **テストベクトル**：`seedFor`・`splitmix32`・Beta抽選の値は、Node 24.21.0とNode 25.2.0で一致した。

### DPの微小確率の打ち切り（PR #86レビュー対応）

旧版は「生きている確率が1e−9未満ならその抽選の計算をやめる」打ち切りをしていた。これはH日以内に到達しうる確率も捨てるため、累積確率が閾値の近くにあると分位点が変わる。レビューで示された例（開始DONE・`requiredFutureDone = 1`・`K = 2`・`H = 10`、等重みの`(a,b) = (0.9999999995, 0.5)`と`(1e−10, 1e−10)`）では、正しいP50は3日（`CDF(3) = 0.5000000000875`）だが、打ち切りありでは5日になった（Node 24.21.0で再現）。

対応：確率の大きさによる打ち切りを廃止し、計算を省くのは「残り日数で届かない状態」と「生きている状態が無くなった後」だけにした（どちらもH日以内の累積確率を変えない）。浮動小数点の丸め誤差は残るため、分位点は`累積 ≥ q − 1e−12`で判定する。`dp-truncation-check.mjs`（Node 24.21.0）の結果：

- レビュー例：P50 = 3日（旧実装の再現は5日）
- `requiredFutureDone = 1`の独立した式`F(d) = 1 − 平均[(1−a)(1−b)^(d−1)]`との照合：0や1に近い抽選値を含む4,000件で分位点が一致。累積確率の最大誤差は2.9e−15。閾値との差が1e−12未満の同点に近いケースは1件あり、同じ規則で一致
- 刈り込みあり／なし：600件で分位点が一致（累積確率の差は0）
- 累積確率が閾値にちょうど一致する例（`F(1) = 0.5`）：P50 = 1日

修正前後で、`bench2.mjs`の12条件と`final2.mjs`の完了の目安（seed違い5回を含む）の分位点は変わらなかった。既定seed・K=200の事後抽選からレビュー例のような同点に近いケースが出るかは確認していない（Beta(2,2)以上の事後分布で、0や1に極端に近い値はほぼ出ない）。

## 記録漏れの影響（2状態、60日×200人）

やらなかった日の記録が確率mで抜ける場合（真のa = 0.8、b = 0.3）：m = 0で推定b 0.34、m = 0.3で0.40、m = 0.6で0.54。bが高めに出るため、遠ざかる日数は小さめ（控えめ側）、完了の目安は早め（楽観側）になる。
