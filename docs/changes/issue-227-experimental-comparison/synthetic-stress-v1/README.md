## 固定条件と指標

[評価前宣言](predeclaration.json)に全8生成規則、seed4401001–4401004、開始日2026-01-05、stream、予算、比較器、採点を固定。宣言時の未実行statusは当時の記録として残した。新規残量5、設定量1、1履歴1fit／1予測を凍結してから未来256本を生成し、悪いseedを交換しない。真のstate／age／未来／潜在run長をモデルへ渡さない。

整数入力に合わせ全量を厳密に2倍（実量.5/1/1.5→1/2/3、残量5→10）し、実累積量で完了日を採点。5回DONEへ置換しない。UNKNOWNはSKIPPEDへ補完しない。[実行前補足](execution-clarifications.json)どおり、origin未観測時の仮TODAY_DONEは診断だけで、観測文脈の候補はnull／STUDY_ORIGIN_UNOBSERVEDに残した。

RPSは `mean_future(sum_{d=1..30}(F(d)-到達label(d))²/30)`。CDFをH内到達に再正規化しない。Brier7/14/30、finite率、条件付きcoverage、pointwise Wilson95 MC区間は[全32CSV](all32.csv)に残す。[小集計JSON](aggregate.json)は同じ全32／候補available同一30の分母を明示する。
